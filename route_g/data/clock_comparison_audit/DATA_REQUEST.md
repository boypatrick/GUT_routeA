# G-R5 missing-record checklist (not sent)

This is an internal request specification, not an email or lab agreement.
No researcher has been contacted. User direction is required before
external coordination. The public data/provenance are recorded separately.

## Intended comparison

Same-ion 171Yb+ E2/E3 readings during at least two independently
characterized radiation environments, plus a second independent E3
clock outside the altered enclosure if common target-reference response
is to be studied. Temperature setpoints need not be300/310 K; those are
only the existing calculation's illustrative settings.

## Smallest useful export

1. Timestamped run/transition/clock identifiers, bath-state assignments,
   settled intervals, interrogation and averaging windows, validity flags.
2. Raw servo/comparator values with nominal ratios, scale/sign convention,
   applied offsets and the reference used by the counter or comb.
3. A reversible per-run correction ledger: BBR explicitly separate from
   all other shifts. Include uncertainty and correlation assumptions.
4. Independent radiation calibration at target and reference: sensor
   readings and calibration, geometry/emissivity/view factors, gradients,
   or calibrated spectra. Keep ion motional thermometry separately labeled.
5. Reference drift/cross-talk monitoring, comb/path diagnostics, gravity
   or height changes, timing alignment and relevant heater/systematic logs.
6. The effective covariance or sufficient component data to reconstruct it.

Do not request unrelated lab records, unpublished theory details or
personal data. A narrowly scoped export can be anonymized to apparatus IDs.
Ask whether the published ROCIT comparator files can be connected to such
records and whether a controlled thermal modulation was actually performed.
Do not assume that a retrospective timestamp-temperature join can create
an experiment that was never run.

## Gate before any fit

Confirm provenance, ratio direction, same target environment, genuinely
distinct thermal states, independent calibration, correction reversibility,
sampling alignment and common-reference covariance. If the bath was
inferred from the tested clock shift itself, label it dependent evidence,
not an independent validation. Missing values are not set to zero.

If no qualifying campaign exists, decide whether to arrange a new experiment
or leave empirical validation open. Existing public clock-ratio data cannot
by themselves supply the missing temperature experiment.
